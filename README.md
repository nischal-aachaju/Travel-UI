# 🌍 WANDER — Travel Website UI Mockup

**WANDER** is a **frontend-only UI mockup** of a modern travel discovery website focused on destinations in the Philippines.  
This project is purely a **design + frontend implementation** intended to showcase layout, visual hierarchy, and component structure — **no backend, authentication, or real booking logic is implemented**.

---

### Created by nyniraula and nischal Aachaju.

## 🎯 Purpose of This Project

- Practice and showcase **modern frontend UI design**
- Translate a high-fidelity layout into clean, reusable components
- Demonstrate understanding of:
  - Section-based page architecture
  - Card-driven layouts
  - Spacing, typography, and visual balance
- Serve as a **portfolio-ready UI concept**, not a production app

---

## 🖥️ What This Is (and Isn’t)

### ✅ This is:

- A static frontend UI
- A landing page + sections layout
- Component-based React structure
- Styled using Tailwind CSS
- Optimized for visual presentation

### ❌ This is NOT:

- A real booking platform
- Connected to any backend or API
- Using authentication or payments
- Production-ready business logic

---

## ✨ UI Sections Implemented

- **Navigation Bar**
  - Brand logo
  - Page links
  - Search input (visual only)
  - Primary CTA button

- **Hero Section**
  - Large destination background
  - Bold headline & supporting text
  - Call-to-action buttons

- **Why Choose WANDER**
  - Trust indicators
  - Feature cards (local expertise, booking, support)

- **Top Destinations**
  - Destination cards with:
    - Images
    - Ratings
    - Pricing (mock data)
    - Location tags

- **Tour Packages**
  - Highlighted packages
  - Visual emphasis over text

- **Footer**
  - Navigation links
  - Social links (non-functional)
  - Status indicator (UI only)

---

## 🛠️ Tech Stack

- **React**
- **Vite**
- **Tailwind CSS**

No state management libraries, APIs, or backend services are used.
